# Daily Chat Mindmap

按以下流程生成每日总结与思维导图：

1. 时间窗口
- 使用 Asia/Shanghai 时区。
- 仅统计当天 00:00-18:40 之前的会话内容（定时触发时）。

2. 覆盖渠道
- QQ
- Telegram
- webchat

3. 主结构（固定）
- 今日完成项目（主类目）
  - QQ-今日完成任务
  - Telegram-今日完成任务
  - Webchat-今日完成任务
- 跨渠道汇总（可选）

4. 每个渠道任务三子类目（固定顺序）
1) 需求
2) 如何完成 / 做了什么修改
3) 结果如何 / 是否完成

5. 抽取与归一化规则
- 以“完成项目”优先：先写已完成，再写部分完成，最后未完成。
- 每个项目必须包含三段信息；缺失信息用“待补充”。
- 结果字段必须带状态：已完成 / 部分完成 / 未完成。
- 跨渠道同一事项去重，保留最完整条目，其余在渠道内简写“同上（跨渠道）”。

6. 输出文件
- 总结：reports/daily/{{date}}-summary.md
- 导图源：reports/mindmap/{{date}}-mindmap.md

7. 输出格式
- 使用 Markdown 标题和列表。
- 每个条目尽量用动词开头（修复/重构/发布/确认/同步/回滚）。
