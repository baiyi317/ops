# ops

这个仓库用于沉淀「每日聊天总结 + 思维导图」自动化流程与产物。

## 主要内容

- `skills/daily-chat-mindmap/`：每日聊天整理技能（SKILL.md）
- `reports/templates/`：日报/导图模板
- `reports/daily/`：每日总结产物（Markdown）
- `reports/mindmap/`：思维导图产物（`.xmind`）

## 当前规则（已落地）

- 每日定时整理（北京时间）
- 覆盖渠道：QQ + Telegram + webchat
- 导图主类目：
  1. 今日所有信息总结
  2. 今日完成任务
  3. 今日未完成任务
  4. 待完成任务
  5. 跨渠道汇总
- 保留 `v5` 作为当前可用模板风格基线

## 使用方式

1. 按模板生成当日总结与导图源文件
2. 产出 `.xmind` 文件并在 XMind 中查看
3. 根据需要继续微调主题与节点样式
